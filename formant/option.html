概览

从左侧切换模块：功能（含 Discord / freefq / huavod / elitepvpers / Gemini 去水印 / Gmail 邮箱 / HLS 播放等总开关）、New Tab、V2EX、GitZip、自动翻页、手势、代理、扩展、词库、翻译、X 推文与同步。

功能

翻译 / New Tab / Discord 聊天翻译 / elitepvpers 帖子翻译 / freefq 导出 / huavod 控制台 / Gemini 去水印 / Gmail 邮箱 / HLS 播放等能力的总开关与细分开关。

New Tab

主页外观、天气城市、搜索框与主页数据同步。

V2EX Plus

自动签到、未读角标、主题/回复增强与用户管理。

GitZip

公开 GitHub 仓库的文件、目录、多选项 ZIP 下载。

AutoPagerize

滚动到底部自动加载下一页；内置站点规则与 microformat 兼容。

鼠标手势

右键划动：后退 / 前进 / 刷新 / 关标签 / 到顶 / 到底。映射可同步 mono。默认关闭，避免与 smartUp 双触发。

代理

默认系统代理；支持 PAC 导入与固定 HTTP·SOCKS；popup 可快速切换。

扩展

搜索并一键启用 / 禁用已安装扩展；popup 顶栏也可开关。

词库

内置多语言俚语包，可导入/新建自定义包，供智能翻译打分使用。

翻译

默认引擎模式与目标语言；与 popup / 划词翻译共用。

X 推文

x.com 时间线自动译推文；用颜色和字号与原文区分。走 Google 直连，不扣 Client API Key。

识图

从 popup 顶栏「工具箱」进入，上传图片或填 URL，用你自己的视觉模型反解提示词。不走 mono。

同步

mono Base URL、Client API Key。不同 Key 对应不同的 New Tab、手势、书签与热点英语。

站点数据

Telegram 下载

默认开启。仅作用于 Telegram Web：在禁止保存内容的群组 / 私密频道里，为已经能看到的图片和视频补下载按钮。关闭后立即停用。

X 推文翻译

默认开启。在 x.com / Twitter 时间线为可见推文补译文（Google 直连，不走 mono）。颜色和字号在「X 推文」面板。关闭后立即停用。

Discord 翻译

默认开启。在 discord.com 聊天页右下角放一个「翻译」按钮，点一下只翻当前频道里已经加载的这一页消息。往上滚出更早的历史时不会自动翻，需要再点一次。刷新页面后这次的译文记录清空。聊天消息翻译用 Google 直连，不走 mono。输入框右侧另有一个翻译图标（样式与旁边的图标一致）：点一下选「Google」或「GPT」，译文直接写入输入框，原文贴在输入框正上方，可一键撤回（GPT 走 mono，消耗 Client API Key，只在你点选时调用）。颜色和字号与「X 推文」面板共用。关闭后立即卸按钮、图标和译文。

elitepvpers 翻译

默认开启。只给 www.elitepvpers.com 的帖子标题和楼层正文补译文（列表标题、帖子页标题、每楼标题与正文），不翻导航、用户名和签名。Google 直连，不走 mono。颜色和字号与「X 推文」面板共用。关闭后立即停用。

linux.do 列表

默认开启。把 linux.do 话题列表换成 formant 风格的文件表格（参考飞书表格结构，不改品牌/侧栏，不碰帖子详情）。关闭后立即恢复原列表。若已装同类油猴会叠皮，关掉其一即可。

虎扑帖子

默认开启。把 bbs.hupu.com 的顶栏、帖子页和板块列表换成 formant 的简洁风格：去掉 App 推广与灰底粗框，回帖行距收紧，「点灭 / 只看此人 / 举报」悬停才出现，帖子里的表情包统一高度、大图限制最大边。帖子详情提供上一帖 / 下一帖（按板块列表顺序）；直接打开详情也会去板块列表里找邻居，不依赖从列表带过来的上下文。只改样式与翻帖，不碰登录与发帖。关闭后立即恢复站点原样。

freefq 导出

默认开启。在 freefq.com 帖子详情页彻底放开划选/复制/右键（站点页尾脚本也会被压住），并提供「导出 TXT」。关闭后立即卸按钮并恢复站点原限制。

huavod 控制台

默认开启。拦截 huavod.com 上的 disable-devtool，避免开 DevTools 被 history.back 踢走；关闭后恢复站点原检测。

Gemini 去水印

默认开启。在 gemini.google.com 和 business.gemini.google 下载生成图时，去掉右下角 Gemini 水印再保存。只处理 googleusercontent 上的成图（路径以 gg / rd 开头），并尽量取原图尺寸。对话文字、导航和其它网站不受影响。关闭后下一次下载恢复带水印原图。不另开面板，不同步到 mono。

Gmail 邮箱

默认开启。只在 mail.google.com 顶栏的问号和设置左边显示当前登录的 Google 邮箱，点击即可复制。其它网站不注入。关闭后这块文字立即去掉。不另开面板，不同步到 mono。

Axure 原型

默认开启。用 file:// 打开本地发布的 Axure HTML 原型时，在各框架之间转发页面消息，并在首页标上 pluginDetected。没有 Axure 事件节点的本地文件不会挂监听。关闭后立即停掉转发。不另开面板，不同步到 mono。Edge / Chrome 扩展详情里还要打开「允许访问文件 URL」。若仍装着 Axure RP Extension，请关掉其一，避免同一条消息发两次。

Vue 组件

默认开启。在 DevTools 里增加「Vue」面板，查看 Vue 3 / Vue 2 的组件树、props / setup / data，以及 Pinia 或 Vuex 的当前状态，并在页面上高亮选中组件。当前标签检测到 Vue 时，工具栏图标右上角会出现绿色 V。关闭后已打开的页面停止检查，图标恢复，新页面不再注入。不另开 popup，不同步到 mono。生产构建需要带 Vue 的 devtools 标志。若仍装着 Vue.js devtools，请关掉其一，避免抢同一个 hook。

HLS 播放

默认开启。主框架打开以 .m3u8 结尾的地址时，改在扩展内用 hls.js 播放，可调倍速和旋转，左右键快进快退，并可把当前列表存成 MP4。地址栏输入 m3u8 再回车也能打开播放页。关闭后这些地址回到浏览器默认下载。不另开面板，不同步到 mono。若仍装着 Native HLS Playback，请关掉其一，避免抢同一次导航。

识图

默认开启。入口在 popup 顶栏「工具箱」页的左侧列表里，识图是工具箱内的左右布局面板；上传或填写图片 URL 后，用「识图」面板里的模型反解提示词。关闭后工具箱里隐藏识图，模型配置保留。不走 mono，不注入网页。

工具箱

默认开启。popup 顶栏「工具箱」图标打开新标签页，内含二维码、时间戳、JSON 美化、JSON 对比、图片 Base64、编码转换、企业查询、象棋，以及识图入口。全部在本机运行，不走 mono，不注入网页，不新增权限。关闭后隐藏这些工具；若识图仍开启，工具箱入口保留且只显示识图。

New Tab

管理主页外观、天气城市和主页数据。「刷新数据」从当前 Client API Key 拉取；「同步主页」上传到该 Key（空主页或较旧本机不会覆盖云端）。打开 New Tab 会自动拉取较新的云端主页。

限制

  • 只认右键划动，不改工具栏 popup，也不调用 contextMenus.removeAll()。
  • 浏览器禁止向 edge://、chrome://、扩展商店（含 Edge Add-ons）和 PDF 查看器注入脚本，这些页无法用手势。
  • 若同时开着 smartUp，两套手势会抢右键。请只开其中一个。

本机钥匙

导出一份 JSON，换电脑时再导入。可以选文件，也可以把 JSON 贴在下面。包含同步的 Base URL 与 Client API Key、识图的 Base URL / API Key / Model、V2EX 的 Imgur Client ID，以及翻译的 DeepLX API Key。New Tab、手势、词库、代理和功能开关不在这份文件里。

说明

  • New Tab 主页、热点英语、鼠标手势、书签按 Client API Key 隔离：每把 Key 一份云端数据，互不可见。
  • 换 Key 会清空本机 New Tab / 词卡 / 手势缓存，避免串数据；请到对应面板点「刷新」拉取。
  • 功能开关、代理、词库包、V2EX 只存在本机，不跟 Key 走。
  • 保存时会请求对应域名的 host 权限。
  • 密钥仅保存在本机 chrome.storage.local，不会写入扩展包；界面只显示 Key 指纹，不展示全文。
  • 书签同步由后台 service worker 执行，与 popup「书签」页同一通道。
