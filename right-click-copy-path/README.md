# 右键复制路径

Windows 右键菜单命令。右键文件夹选择“复制文件夹路径”，或右键文件选择“复制文件路径”，即可将所选对象的完整路径复制到剪贴板。

在资源管理器中选中一个或多个文件、文件夹后，按 `Alt+F2`。多选时，每条完整路径占一行。快捷键需要一个随登录启动的小型后台进程；只在资源管理器窗口处于前台且有选中项目时复制。在 Zed 等其他程序中，`Alt+F2` 仍由该程序自身处理。

## 安装

在 PowerShell 中进入本目录，运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

安装脚本使用 Go 编译 `CopyFolderPath.exe`，然后在当前用户的注册表中添加文件、文件夹菜单项及登录启动项，并立即启动快捷键监听；无需管理员权限。Windows 11 中，右键命令通常位于“显示更多选项”。安装后请保留本目录及生成的文件，不要移动它。若已从旧目录安装过，请运行本目录的安装脚本来更新程序路径。

## 卸载

```powershell
powershell -ExecutionPolicy Bypass -File .\uninstall.ps1
```

卸载脚本移除菜单项和登录启动项，并停止快捷键进程；如不再需要，可随后删除本目录。
